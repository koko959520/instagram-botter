# LIVRE 11 — LA CITÉ DE CUIVRE (Épisodes 501 à 550)

| | |
|---|---|
| **Lieux** | Le Ghayb : Madinat an-Nahas (Cité de Cuivre), Rues du Silence, Cachots de Laiton, Désert de la Soif, Seuil de la Page |
| **Antagonistes** | **Sakt (Silence)** · **Zamma (Soif)** · les Veilleurs (faux alliés) |
| **Niveau d'Idriss** | 380 → 420 · Rang public : hors échelle |
| **Gardiens** | Retour de Dieli au premier plan ; la Légion reste dans le monde visible |
| **Mort** | **Moussa Keïta** (ép. 538) |
| **Émotion** | Retrouvailles, adieu, amnésie |
| **Révélation** | Moussa est la batterie vivante du Ghayb ; Nour est la Page ; les Veilleurs effacent Idriss |
| **Splash majeur** | Ép. 500/502 (la Cité) · Ép. 526 (père et fils) · Ép. 538 (sacrifice) · Ép. 548 (effacement) · Ép. 550 (Nour écrit) |

**Promesse du Livre** : le héros retrouve son père — et le perd. L'héroïne devient protagoniste.

*Règles du Ghayb : un Nom est une matière. Perdre son nom = disparaître. Le temps est élastique. Le son se vend.*
