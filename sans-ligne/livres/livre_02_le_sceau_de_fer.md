# LIVRE 2 — LE SCEAU DE FER (Épisodes 51 à 100)

| | |
|---|---|
| **Lieux** | Tours du Soleil, Marché Rouge, Port du Fleuve (entrepôt 9), route du sel, Taoudenni, Sarab Clos du Sel |
| **Antagonistes** | La Caravane d'Or (Hamidou Diop) · le Roi du Sel · Moustapha Doumbia (en filigrane) |
| **Niveau d'Idriss** | 40 → 85 · Rang public : **Cuivre → Fer** |
| **Gardien gagné** | **Fennek** (ép. 61) |
| **Compétences** | Voile du Simoun, premier usage public du Pas du Mirage, Inscription des Noms maîtrisée |
| **Émotion** | Camaraderie, suspicion |
| **Révélation** | La poussière de Sarab vient d'une brèche à Taoudenni ; Moussa y est passé ; Baba Salim parle des Neuf Trônes (ép. 98) |
| **Splash majeur** | Ép. 60 (le renard dans la cage) · Ép. 76 (la porte de sel) · Ép. 89 (la chute du Roi du Sel) · Ép. 100 (l'ombre de Zamma) |

**Promesse du Livre** : il n'est pas seul à le voir — Safiya devient le premier témoin ; et le père laisse des traces.
